# Tetris-4-wide-AI-project
Tetris AI that plays on 4-wide board to maximize combo. WUMBOTIZE EVERYONE! This project was inspired by bots on the tetrio platform, such as mochbot and zzztoj. The speed of the bot and the accuracy of the moves of the bot can be changed by adjusting the maxdepth variable, which controls the depth of the expectimax tree. The optimized version main_v2 uses a bitboard system to significantly increase the performance. main_v1 uses a 2d array system. For main_v2, I only used chatgpt to rewrite basic functions for clearing lines and board representation. The program includes the interface for the tetris game, which the bot is playing. To run this program, download the files for orientations_v2 and main_v2.
